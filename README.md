# Restaurant Website

A restaurant website developed using C# and ASP.NET Core in Visual Studio Code.

This project was created to practise web application development, Git/GitHub version control, and AI-assisted software development using GitHub Copilot.

## Technologies

- C#
- ASP.NET Core
- HTML/CSS
- Visual Studio Code
- Git
- GitHub
- GitHub Copilot

## Features

- Restaurant information
- Food menu presentation
- Responsive web interface
- Razor Pages structure
- Static images and styling

## Project Structure

- `Pages/` – Razor Pages and website content
- `wwwroot/` – CSS, JavaScript, images and static files
- `Properties/` – Application configuration
- `Program.cs` – Application startup and configuration
- `appsettings.json` – Application settings
- `HearthAndHarvest.csproj` – C# project configuration

## Running the Project

Make sure the .NET SDK is installed.

Clone the repository:

    git clone <repository-url>

Open the project folder:

    cd Restaurant-Website

Restore the project:

    dotnet restore

Run the application:

    dotnet run

Open the local URL displayed in the VS Code terminal.

## Version Control

Git and GitHub are used for version control to:

- Track code changes
- Create commits
- Maintain development history
- Push changes to the remote GitHub repository
- Practise branch and merge workflows
